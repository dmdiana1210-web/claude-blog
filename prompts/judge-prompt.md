# Промпт LLM-judge — оценка стиля статьи

## Задача

Оценить стиль статьи для HR-дайджеста по 8 проверяемым правилам и качественно.
Вернуть вердикт «прошёл» или «есть замечания» и 2–3 коротких замечания.

## Контекст

HR-дайджест про подбор, адаптацию, мотивацию и развитие сотрудников.
Аудитория — HR-специалисты, рекрутеры и руководители.
Стиль — разговорный, материал читается как корпоративный блог, а не как инструкция.

## Правила (проверяются по «да/нет»)

1. **Объём** — статья содержит 300–500 слов.
2. **Абзацы** — каждый абзац не длиннее четырёх строк.
3. **Обращение** — текст обращается к читателю на «вы», без обращения на «ты».
4. **Первое лицо** — в тексте есть хотя бы одна форма первого лица («я заметила», «мы рекомендуем»).
5. **Начало** — статья не начинается вопросом к читателю.
6. **Эмодзи** — в статье не более двух эмодзи.
7. **Канцелярит** — в тексте нет оборотов «в данном материале рассматривается», «следует отметить, что», «необходимо обратить внимание».
8. **Формулировки** — правила можно проверить по «да/нет», формулировок «пиши живо» нет.

## Что оценить качественно (помимо правил)

- Попадание в аудиторию HR-специалистов.
- Живость и читабельность, отсутствие сухости.
- Практическая польза: есть ли действие, которое читатель может применить.

## Формат ответа

Верни JSON:

```json
{
  "verdict": "passed | issues",
  "summary": "одна строка с общей оценкой",
  "remarks": [
    "замечание 1",
    "замечание 2"
  ]
}
```

- `verdict`: `passed`, если нарушений правил нет и качество acceptable.
  `issues`, если есть нарушение хотя бы одного правила или серьёзное замечание по качеству.
- `remarks`: 0–3 коротких замечания. Если всё хорошо — пустой массив.
