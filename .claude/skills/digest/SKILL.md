Сделай выпуск дайджеста на тему: $ARGUMENTS

Сегодня: !`date +%Y-%m-%d`
Текущая ветка: !`git branch --show-current`
Незакоммиченные изменения: !`git status --short`

Если список незакоммиченных изменений не пуст — остановись и скажи об этом.
Выпуск из грязного рабочего дерева не делаем.

1. Через Tavily найди 3 главные новости по теме за последнюю неделю. Три разных события, не три пересказа одного.
2. Прочитай редполитику в .claude/rules/article-style.md и пиши строго по ней.
3. Каждую новость — отдельной статьёй в src/content/blog/<дата>-<slug>.md.
   Метаданные в начале файла — как в src/content.config.ts: title, description, pubDate, category, cover, source, tags.
4. Обложку для каждой статьи подбери навыком /cover. Статью без поля cover не сохраняй.
5. Перед коммитом открой каждую ссылку из source и убедись, что она работает.
6. Добавь в git только новые статьи, закоммить с описательным сообщением, push в текущую ветку (не в main: в main у нас только через PR).

Не задавай уточняющих вопросов. Допущения перечисли в конце.
