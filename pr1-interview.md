# Архитектурное интервью — PR-1

Формат: «Вопрос Claude → Мой ответ». Ниже — только вопросы и ответы, зафиксированные в ходе интервью. Вопросы сгруппированы по трём блокам: архитектурные решения, уточнения по реализации, финальные параметры.

## Блок 1. Архитектурные решения

**Вопрос Claude:** Как публиковать сгенерированные статьи — автоматически или через ревью?
**Мой ответ:** Публикация — через PR с ревью.

**Вопрос Claude:** Как и когда запускать генерацию?
**Мой ответ:** Запуск — еженедельно по cron + вручную.

**Вопрос Claude:** Сколько статей генерировать за один прогон?
**Мой ответ:** Объём — одна статья за прогон.

**Вопрос Claude:** Где исполнять пайплайн и как хранить секреты?
**Мой ответ:** Исполнение — GitHub Actions, секреты в GitHub Secrets.

**Вопрос Claude:** Как проверять стиль сгенерированной статьи?
**Мой ответ:** Проверка стиля — линтер + LLM-judge в PR.

**Вопрос Claude:** Как выбирать тему для следующей статьи?
**Мой ответ:** Выбор темы — ротация категорий + ранжирование.

## Блок 2. Уточнения по реализации

**Вопрос Claude:** Какой LLM-провайдер и какой секрет использовать?
**Мой ответ:** LLM-провайдер — Anthropic Claude API, секрет `ANTHROPIC_API_KEY`.

**Вопрос Claude:** Одинаковые ли модели использовать для генерации статьи и для LLM-judge?
**Мой ответ:** Для генерации статьи и для LLM-judge использовать разные модели: для статьи — более качественную, для judge — более дешёвую.

**Вопрос Claude:** Какой день недели и время для cron-запуска?
**Мой ответ:** Cron — понедельник, 07:00 UTC.

**Вопрос Claude:** Кто заполняет бэклог тем `topics.json`?
**Мой ответ:** Бэклог тем `topics.json` заполняем вручную.

**Вопрос Claude:** Кто мерджит PR и нужен ли CODEOWNERS?
**Мой ответ:** PR мерджу вручную я. CODEOWNERS пока не нужен.

## Блок 3. Финальные параметры

**Вопрос Claude:** Стартовый набор тем для `topics.json` — заполнить первыми 2–3 темами на разные категории или ты наполнишь файл сама?
**Мой ответ:** Заполнить 2–3 темами.

**Вопрос Claude:** Branch protection (требовать зелёный линтер для мерджа PR) — настраиваем или пока мерджаешь на своё усмотрение?
**Мой ответ:** Пока без защиты.
