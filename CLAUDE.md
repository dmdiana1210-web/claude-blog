# CLAUDE.md

## WHY

Проект представляет собой HR-дайджест на базе Astro.

Цель проекта — публиковать материалы по подбору персонала, адаптации,
мотивации и развитию сотрудников.

Аудитория — HR-специалисты, рекрутеры и руководители.

## WHAT

Контент — это Astro Content Collection `blog`. Статьи лежат в
`src/content/blog/` как Markdown-файлы; просто положить файл в папку
недостаточно — его проверяет коллекция.

Frontmatter проверяется Zod-схемой в `src/content.config.ts` — неверное
поле ломает сборку. Адрес страницы строится из имени файла через
`src/pages/blog/[...slug].astro`, поэтому переименование файла меняет URL.

В `astro.config.mjs` стоит placeholder `https://example.com` — при деплое
заменить на реальный домен.

## HOW

- Перед изменением файлов изучай существующую структуру проекта.
- Не изменяй архитектуру без необходимости.
- Не изменяй `.env`.
- Не запускай `run-claude.sh` из открытой сессии Claude Code — он вызывает `claude`, и получится рекурсия и зависание.
- Если информации недостаточно — сначала задай уточняющий вопрос.
- После выполнения задачи кратко объясняй изменения.

## Rules index

Правила вынесены в отдельные файлы. Открывай их перед соответствующей работой:

- **Before writing or editing articles in `src/content/blog/`, read
  `.claude/rules/article-style.md`.** — стиль статей (8 правил), критерии
  отбора новостей (5 правил), редполитика (10 правил).
- **Before committing or opening a PR, read
  `.claude/rules/git-conventions.md`.** — формат коммитов, длина subject line,
  именование веток, целевая ветка PR.

## Digest Pipeline

Автоматический AI-дайджест: запуск по расписанию и вручную (см.
`.github/workflows/generate-digest.yml`), генерация одной статьи за прогон,
публикация через PR с ревью.

- **Количество новостей** — одна статья за прогон.
- **Путь и имя файла** — `src/content/blog/YYYY-MM-DD-<slug>.md`, где `<slug>`
  — латиница в kebab-case. Дата в имени совпадает с `pubDate`.
- **Обложка** — 1200×630 пикселей, путь в поле `cover`, файл в `public/covers/`.
- Стиль, критерии отбора и редполитика — см. `.claude/rules/article-style.md`.
