# Отчёт по ПР-2: работа с @mentions

## 1. Использованные промпты с @mentions

1. Посмотри @CLAUDE.md и скажи, каких правил в нём не хватает для дайджеста.
2. Посмотри @src/pages/ и перечисли, какие страницы уже есть.
3. Посмотри @src/pages/index.astro#1-30 и объясни, что делает эта часть.
4. Посмотри @terminal:zsh — что выводит сервер.

## 2. Сравнение одного вопроса без @mentions и с @mentions

**Вопрос:** объяснить, как устроена главная страница и откуда она получает статьи.

- **Без @mentions:** «Объясни, как устроена главная страница проекта и откуда она получает статьи.»
  Claude сам ищет нужные файлы и читает их по очереди.
- **С @mentions:** «Объясни, как устроена главная страница проекта и откуда она получает статьи. Посмотри @src/pages/index.astro и @src/content.config.ts»
  Claude читает ровно указанные файлы, без отдельного поиска.

## 3. Количество использованных файлов

| Режим | Файлов прочитано |
|---|---|
| Без @mentions | 3 |
| С @mentions | 2 |

С @mentions модель обращается только к заданным файлам, без лишних обращений.

## 4. Результаты /cost

В обоих случаях числовое значение недоступно:

> Usage tracking is only available for Claude AI subscribers

Причина: авторизация через Anthropic Console, а не через подписку Claude AI.

## 5. Вывод

@mentions позволяют точно указать, какие файлы читать, поэтому Claude обращается к двум файлам вместо трёх и не тратит обращения на поиск. Ответ становится точнее, потому что модель работает с заданным контекстом, а не выбирает файлы сама. Сравнить стоимость не удалось — при авторизации через Anthropic Console /cost недоступен.
